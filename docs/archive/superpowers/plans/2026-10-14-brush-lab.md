# Brush Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Brushes become settings (with a style, a texture, a name and a seed), the bar's six drawing tools become six open tool slots that hold any library brush, and a new Brush Lab screen makes, tests, tweaks, names, saves and shares brushes.

**Architecture:** Everything that decides what a brush is lives in pure Java, checked on the desktop: the settings table (`BrushSetting`), styles (`BrushStyle`), share codes (`BrushCode`), textures (`BrushTexture`, `PaperGrain`), names (`BrushNames`, read from text assets through `Assets`), built-ins (`BuiltinBrush`), the slot value (`Brush`), captions and variations, the library (`BrushLibrary`), the six slots with undo and migration (`ToolSlots`, replacing `WildBrushes`) and the lab's own state and undo (`BrushLab`). The drawing screen (`InkWash`, `InkWashBar`, `DrawingPad`, `PaintActivity`) is rewired from the fixed `InkWash.Tool` enum to slots. The lab is a second activity (`BrushLabActivity`) whose views (`BrushTestPad`, `LabSettings`, `LabLibrary`, `LoopCard`, `BandSlider`, `SquareSwitch`, `LabButton`) only show `BrushLab` and call it. Strokes always start in one place, `InkWash.stroke(...)`, for the drawing screen, the lab's test page and every sample.

**Tech Stack:** Java 8 Android app (no Kotlin, no XML layouts), desktop checks run by `bash scripts/test_inkwash.sh` (plain `main` methods with a `check(boolean, String)` helper, no JUnit), Phosphor icons (Bold) as VectorDrawables.

**Source of truth:** `docs/archive/superpowers/specs/2026-10-14-brush-lab-design.md` (including its "Open tool slots" section). **Reference implementation:** the second `<script>` of `docs/brush-lab/brush-lab-mockup.html`; each task names the mockup functions it ports. **Decisions this plan makes where the spec or mockup left room** (also recorded in the spec's as-built notes in Task 18):
1. **Brush identity** is `WildBrush.key()`: the share code without name and style (kind letter, every setting, seed). Looks, samples and wet-paint joining key on it. Storage is the share code, so a stored brush is its code's (quantised) settings; a fresh roll is quantised the first time it is stored, a change under 1/1295 of a dial's range.
2. **Share code fixes** over the mockup's `encode`: a dial is clamped into its range before it is written (the mockup wrote a round nib's aspect 1, past the Nib width range, as three digits, so every round-nib code failed to decode); Speed at amount 0 is written 647 (thinner when fast) or 648 (thicker), which the mockup's `decode` already reads as the right direction.
3. **Textures** carry no extra spread: the plain paper keeps its 1.22 spread for tooth and wobble (`WildInkStroke`'s `NOISE_SPREAD`, moved to `PaperGrain`), a scan is read as it is, as the mockup does. The mid noise of a scan is a 768-pixel table (the scan at 3×, bilinear), so it tiles.
4. **Samples** draw at a preset: pens Small on tiles under 120 px tall and Medium on cards; paint always Small (the bar's swoosh: see 9). The test area's corner loop is 300 × 220 page pixels, pens at the S/M/L picked, paint at Small (a Medium or Large paint loop can't fit a corner). The corner is drawn into the test page's display over the page and framed; pen-downs inside it are ignored.
5. **Save of a built-in** says it is already in the library (built-ins are library entries now); change it first to make your own. Save of a brush already in the library (same name and settings) says so and counts as using it.
6. **"Most recently used"** for the panel's four tiles: a library entry is stamped when saved or put in a slot (from a tile or from the lab). On a fresh install the built-ins fill the tiles.
7. **Library order in the lab:** the six slots' brushes in bar order (a slot brush that is also a saved entry stands for that entry, which then isn't repeated), then built-ins not in a slot, then the remaining saved brushes newest first. Library edits in the lab (save, delete) write at once; the slot only changes on Back.
8. **Slot keys:** sizes and shades move from `inkwash_size_<TOOL>` to `inkwash_size_slot<i>` (and shades alike), the selection from `INK`… to `slot<i>`; the eraser keeps `ERASER`. Migration runs once, when `tool_slots` is first written.
9. **Bar icons** are the slot brush's swoosh (spec) in the dark shade, filling the 72 × 48 dp button, pens at Medium and paint at Small, paper made clear so the selected (inverted) button tints the dots white. "Too tight" means the bar is shorter than menu, undo, redo, six wide slots, the eraser, the two add buttons and four layer thumbnails (924 dp); then slots are 48 dp squares with the same swoosh.
10. **Test area** = a new small view, `BrushTestPad`: `DrawingPad` is bound to `PaintActivity` (about 100 references to it), so it can't host a scratch page. The pad drives the real strokes through `InkWash.stroke`, blocks the firmware ink with `NativePen.prepareDocumentCanvas`, presents through `DirectEink` mode 7 and refreshes the whole pad 2 s after the pen goes away, as the drawing screen does. Pen input is read by `PenSample`, extracted from `DrawingPad.sampleEvent` so both read pens the same way.

```java
package io.github.mpdairy.monopaint;

import java.io.ByteArrayOutputStream;
import java.io.File;
import java.io.FileInputStream;
import java.io.IOException;
import java.io.InputStream;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;

/**
 * The app's bundled files (app/src/main/assets): paper textures and name lists. Where they are read from
 * is installed once at startup: the APK's assets on the device, the repository's assets folder in the
 * desktop checks. Pure, checked on the desktop.
 */
final class Assets {
    /** Opens an asset by its path under the assets folder, e.g. "names/produce.txt". */
    interface Source { InputStream open(String path) throws IOException; }
    /** The repository's assets folder, for the desktop checks, which run from the repository's root. */
    static final String FOLDER = "app/src/main/assets";
    private static volatile Source source;

    private Assets() { }

    /** Where assets are read from. The first install stands, so every activity may call it in onCreate. */
    static synchronized void install(Source from) { if (source == null) source = from; }
    /** Files under {@code directory}, by their asset path. */
    static Source folder(String directory) { return path -> new FileInputStream(new File(directory, path)); }
    static byte[] bytes(String path) throws IOException {
        Source from = source;
        if (from == null) throw new IOException("No assets installed, reading " + path);
        try (InputStream in = from.open(path)) {
            ByteArrayOutputStream out = new ByteArrayOutputStream();
            byte[] buffer = new byte[16384];
            for (int n; (n = in.read(buffer)) > 0; ) out.write(buffer, 0, n);
            return out.toByteArray();
        }
    }
    /** A text asset's lines, trimmed, blank lines left out. */
    static List<String> lines(String path) throws IOException {
        List<String> lines = new ArrayList<>();
        for (String line : new String(bytes(path), StandardCharsets.UTF_8).split("\n")) {
            String trimmed = line.trim();
            if (!trimmed.isEmpty()) lines.add(trimmed);
        }
        return lines;
    }
}
```

```java
package io.github.mpdairy.monopaint;

import java.io.IOException;
import java.util.Collections;
import java.util.List;
import java.util.Locale;
import java.util.Random;

/**
 * Names for new brushes and drawings, from plain text files Elling can edit (assets/names, one name a line):
 * an adjective and a fruit or vegetable ("dapper-fig"), or now and then a ballplayer from the famously
 * garbled baseball game ("Bobson Dugnutt"). Brushes store their names, so editing the lists renames
 * nothing. Pure, checked on the desktop.
 */
final class BrushNames {
    /** How often a new brush is named after a player rather than adjective-produce. */
    static final double PLAYERS = .25;
    private static List<String> adjectives, produce, players;

    private BrushNames() { }

    static synchronized List<String> adjectives() { if (adjectives == null) adjectives = load("adjectives.txt"); return adjectives; }
    static synchronized List<String> produce() { if (produce == null) produce = load("produce.txt"); return produce; }
    static synchronized List<String> players() { if (players == null) players = load("players.txt"); return players; }

    /** A new brush's name. */
    static String fresh(Random random) {
        if (random.nextDouble() < PLAYERS) return pick(players(), random);
        return pick(adjectives(), random) + "-" + pick(produce(), random);
    }
    /**
     * A variation's name, keeping {@code name}'s family part: a player keeps his surname under another
     * player's first name; any other name keeps its last word under a new adjective.
     */
    static String kin(String name, Random random) {
        int space = name.indexOf(' ');
        if (space > 0) {
            String other = pick(players(), random);
            return other.substring(0, other.indexOf(' ')) + name.substring(space);
        }
        String[] words = name.split("-");
        return pick(adjectives(), random) + "-" + words[words.length - 1].toLowerCase(Locale.ROOT);
    }
    static String pick(List<String> list, Random random) { return list.get(random.nextInt(list.size())); }

    private static List<String> load(String file) {
        try { return Collections.unmodifiableList(Assets.lines("names/" + file)); }
        catch (IOException e) { throw new IllegalStateException("Can't read names/" + file, e); }
    }
}
```

```java
package io.github.mpdairy.monopaint;

/**
 * The paper grain Wild brushes read: a fine noise (about 2 px) and a mid noise (about 6 px), each 0 to 255
 * and fixed to the page. {@link #PLAIN} is today's paper, {@link WatercolorSettle.Paper}'s FINE and MID, so
 * plain brushes draw exactly as before. A texture (see {@link BrushTexture}) replaces both with a scan, as
 * the Brush Lab mockup's useTexture does: fine is the 256-pixel scan itself, mid the scan at three times the
 * scale, smoothed (bilinear), so it tiles every 768 pixels. Pure, checked on the desktop.
 */
final class PaperGrain {
    /** A scan's side and the plain fine table's: a power of two, so a page position masks into it. */
    static final int SIDE = WatercolorSettle.Paper.GRAIN_SIDE;
    /** How much larger a scan's mid noise is than its fine. */
    static final int MID_SCALE = 3;
    /**
     * How far tooth and wobble widen the plain paper's noise about its middle: its noises are two octaves
     * stretched to 0–255, so they bunch nearer the middle than the roll tester's one-octave value noise
     * (tooth's blend has a standard deviation of .13 against the tester's .16), which left edges half as
     * ragged. A scan is used as it is, as the mockup uses it.
     */
    static final float PLAIN_SPREAD = 1.22f;
    static final PaperGrain PLAIN = new PaperGrain(WatercolorSettle.Paper.FINE, WatercolorSettle.Paper.MID, SIDE, PLAIN_SPREAD);

    /** {@link #SIDE} square, row by row. */
    final byte[] fine;
    /** {@link #midSide} square, row by row. */
    final byte[] mid;
    final int midSide;
    /** How far {@link WildInkStroke#tooth} spreads this grain's noise about its middle. */
    final float spread;

    private PaperGrain(byte[] fine, byte[] mid, int midSide, float spread) {
        this.fine = fine; this.mid = mid; this.midSide = midSide; this.spread = spread;
    }

    /** The grain of a {@link #SIDE}-square scan, values 0 to 255 row by row. */
    static PaperGrain scan(byte[] scan) {
        if (scan.length != SIDE * SIDE) throw new IllegalArgumentException("A texture is " + SIDE + " pixels square, not " + scan.length + " bytes");
        int side = SIDE * MID_SCALE;
        byte[] mid = new byte[side * side];
        for (int y = 0; y < side; y++) {
            int iy = y / MID_SCALE;
            float ty = (float)(y % MID_SCALE) / MID_SCALE;
            for (int x = 0; x < side; x++) {
                int ix = x / MID_SCALE;
                float tx = (float)(x % MID_SCALE) / MID_SCALE;
                float top = mix(at(scan, ix, iy), at(scan, ix + 1, iy), tx), bottom = mix(at(scan, ix, iy + 1), at(scan, ix + 1, iy + 1), tx);
                mid[y * side + x] = (byte)Math.round(mix(top, bottom, ty));
            }
        }
        return new PaperGrain(scan, mid, side, 1);
    }

    int fine(int x, int y) { return fine[(y & SIDE - 1) * SIDE + (x & SIDE - 1)] & 255; }
    /** Where page row {@code y} starts in {@link #mid}. */
    int midRow(int y) { return Math.floorMod(y, midSide) * midSide; }
    int mid(int x, int y) { return mid[midRow(y) + Math.floorMod(x, midSide)] & 255; }

    private static int at(byte[] scan, int x, int y) { return scan[(y & SIDE - 1) * SIDE + (x & SIDE - 1)] & 255; }
    private static float mix(float a, float b, float t) { return a + (b - a) * t; }
}
```

```java
package io.github.mpdairy.monopaint;

import java.io.IOException;

/**
 * The paper grain a Wild brush shows (see {@link PaperGrain}): plain, today's paper, or a CC0 height map
 * from ambientCG (Paper001 cold press, Paper004 laid, Paper002 felt, Paper005 crumpled, Fabric036 canvas),
 * stored in assets/textures as 256 × 256 raw 8-bit, normalised to mean 128, spread 52. Paper tooth (pens)
 * or Granulation (paints) say how strongly it shows. Never reorder: share codes carry the index.
 */
enum BrushTexture {
    PLAIN("plain", null), COLD_PRESS("cold press", "cold-press"), LAID("laid", "laid"), FELT("felt", "felt"),
    CRUMPLED("crumpled", "crumpled"), CANVAS("canvas", "canvas");

    final String label;
    private final String file;
    private PaperGrain grain;

    BrushTexture(String label, String file) { this.label = label; this.file = file; }

    /** The grain: the paper's for plain, else the scan's, read the first time; the paper's if the scan can't be read, so a brush always draws. */
    synchronized PaperGrain grain() {
        if (file == null) return PaperGrain.PLAIN;
        if (grain == null) {
            try { grain = PaperGrain.scan(Assets.bytes("textures/" + file + ".bin")); }
            catch (IOException | IllegalArgumentException e) { return PaperGrain.PLAIN; }
        }
        return grain;
    }
}
```

```java
        double[] band = band(b, SPEED);
        if (band == null) return null;
        if (band[0] <= 0 && band[1] >= 0) return new double[]{0, Math.max(-band[0], band[1])};
        double a = Math.abs(band[0]), c = Math.abs(band[1]);
        return new double[]{Math.min(a, c), Math.max(a, c)};

    /**
     * A new brush in this style, named afresh, as the mockup's rollIn: in Wild the roll tester's roll of a new
     * seed with a random texture half the time; otherwise every setting within the style's range.
     */
    WildBrush roll(Random random) {
        long seed = random.nextInt() & 0xffffffffL;
        if (ranges == null) {
            WildBrush b = WildBrush.roll(kind, seed);
            b.name = BrushNames.fresh(random);
            BrushTexture[] textures = BrushTexture.values();

    void rollSetting(WildBrush b, BrushSetting setting, Random random) {
        if (setting.choice()) {
            int[] options = options(setting);
            setting.set(b, options != null ? options[random.nextInt(options.length)] : random.nextInt(setting.choices.length));
        } else {
            double[] band = band(b, setting);
            if (band == null && setting.min == 0 && random.nextDouble() < .3) setting.set(b, 0);

        }
        b.normalize();
    }

        /** On {@code chance} of the time, within {@code lo} to {@code hi}; otherwise off. */
        Builder maybe(BrushSetting setting, double chance, double lo, double hi) { ranges.put(setting, new Range(lo, hi, chance, null)); return this; }
        /** One of {@code options}, repeats weighting the dice. */
        Builder pick(BrushSetting setting, String... options) {
            int[] indexes = new int[options.length];
            for (int i = 0; i < options.length; i++) {
                indexes[i] = setting.index(options[i]);
                if (indexes[i] < 0) throw new IllegalArgumentException(setting + " has no option " + options[i]);
            }
            ranges.put(setting, new Range(0, 0, 1, indexes));
            return this;
        }

    private static Builder with() { return new Builder(); }

        list.add(new BrushStyle(kind, name, list.size(), builder == null ? null : Collections.unmodifiableMap(builder.ranges)));
```

```java
package io.github.mpdairy.monopaint;

import java.util.List;
import java.util.Locale;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

/**
 * Share codes, also how brushes are stored, as the Brush Lab mockup's encode and decode: {@code name.K S DIALS.SEED}:
 * the name as a lowercase slug, I (pen) or P (paint), the style's index, each setting in {@link BrushSetting}'s order
 * (a choice as one digit, a dial as two base-36 digits over its range), then the seed in base 36. A dial is clamped
 * into its range before it is written (the mockup wrote a round nib's width past it, so its round-nib codes didn't
 * read back), and Speed at 0 is written just either side of the middle to keep which way it works.
 * Pure, checked on the desktop.
 */
final class BrushCode {
    /** Steps across a dial's range: the most two base-36 digits hold. */
    static final int STEPS = 1295;
    /** Speed's two steps either side of 0: at amount 0 they keep which way speed works. */
    static final int THINNER_AT_ZERO = 647, THICKER_AT_ZERO = 648;
    private static final Pattern CODE = Pattern.compile("([a-z]+(?:-[a-z]+)*)\\.([IP])(\\d)([0-9a-z]+)\\.([0-9a-z]{1,7})");

    private BrushCode() { }

    /** A name as a code carries it: lowercase letters in hyphenated words, "brush" if nothing is left. */
    static String slug(String name) {
        String slug = name.toLowerCase(Locale.ROOT).replaceAll("[^a-z]+", "-").replaceAll("^-|-$", "");
        return slug.isEmpty() ? "brush" : slug;
    }
    static String encode(WildBrush b) { return slug(b.name) + "." + letter(b.kind) + b.style.index + dials(b) + "." + seed(b); }
    /** What makes two brushes draw alike: the code without name or style. See {@link WildBrush#key}. */
    static String settings(WildBrush b) { return letter(b.kind) + dials(b) + "." + seed(b); }

    /** The brush a code describes, its name the code's slug; null if the code doesn't read. */
    static WildBrush decode(String code) {
        if (code == null) return null;
        Matcher m = CODE.matcher(code.trim());
        if (!m.matches()) return null;
        WildBrush.Kind kind = m.group(2).equals("I") ? WildBrush.Kind.INK : WildBrush.Kind.PAINT;
        List<BrushStyle> styles = BrushStyle.of(kind);
        int style = m.group(3).charAt(0) - '0';
        long seed = Long.parseLong(m.group(5), 36);
        if (style >= styles.size() || seed > 0xffffffffL) return null;
        WildBrush b = new WildBrush(kind, seed, m.group(1));
        b.style = styles.get(style);
        String digits = m.group(4);
        int at = 0;
        for (BrushSetting setting : BrushSetting.of(kind)) {
            if (setting.choice()) {
                if (at >= digits.length()) return null;
                int option = digits.charAt(at++) - '0';
                if (option < 0 || option >= setting.choices.length) return null;
                setting.set(b, option);
                continue;
            }
            if (at + 2 > digits.length()) return null;
            int step = Integer.parseInt(digits.substring(at, at + 2), 36);
            at += 2;
            if (setting == BrushSetting.SPEED && (step == THINNER_AT_ZERO || step == THICKER_AT_ZERO)) {
                b.speed = 0; b.thickerWhenFast = step == THICKER_AT_ZERO;
                continue;
            }
            setting.set(b, setting.min + step / (double)STEPS * (setting.max - setting.min));
        }
        return at == digits.length() ? b.normalize() : null;
    }

    private static char letter(WildBrush.Kind kind) { return kind == WildBrush.Kind.INK ? 'I' : 'P'; }
    private static String seed(WildBrush b) { return Long.toString(b.seed & 0xffffffffL, 36); }
    private static String dials(WildBrush b) {
        StringBuilder out = new StringBuilder();
        for (BrushSetting setting : BrushSetting.of(b.kind)) {
            if (setting.choice()) { out.append((int)setting.get(b)); continue; }
            int step;
            if (setting == BrushSetting.SPEED && b.speed == 0) step = b.thickerWhenFast ? THICKER_AT_ZERO : THINNER_AT_ZERO;
            else {
                double v = Math.max(setting.min, Math.min(setting.max, setting.get(b)));
                step = (int)Math.round((v - setting.min) / (setting.max - setting.min) * STEPS);
            }
            String digits = Integer.toString(step, 36);
            if (digits.length() < 2) out.append('0');
            out.append(digits);
        }
        return out.toString();
    }
}
```

```java
/**
 * What a tool slot or a library entry holds: a built-in tool, or a Wild-engine brush. Its kind decides where it
 * draws (pens on the ink layer, paints on the wash layer), not the slot it sits in. Treat it as a value: to
 * change a Wild brush, change a copy. Pure, checked on the desktop.
 */
final class Brush {
    /** The longest name a brush keeps. */
    static final int NAME_MAX = 32;
    /** A built-in, or null. */
    final BuiltinBrush builtin;
    /** A Wild brush, or null. */
    final WildBrush wild;

    private Brush(BuiltinBrush builtin, WildBrush wild) { this.builtin = builtin; this.wild = wild; }
    static Brush of(BuiltinBrush builtin) { return new Brush(builtin, null); }
    static Brush of(WildBrush wild) { return new Brush(null, wild); }

    WildBrush.Kind kind() { return builtin != null ? builtin.kind : wild.kind; }
    String name() { return builtin != null ? builtin.label : wild.name; }
    /** Whether it draws on the ink layer, in ink's sizes and shades. */
    boolean inks() { return kind() == WildBrush.Kind.INK; }
    /** Whether it lays watercolor that stays wet a moment, in Watercolor's sizes and shades: Watercolor and any Wild paint. */
    boolean wet() { return builtin == BuiltinBrush.WATERCOLOR || builtin == null && wild.kind == WildBrush.Kind.PAINT; }

    WildBrush settings() { return builtin != null ? builtin.approximation() : wild; }
    /** The style its dice roll within. */
    BrushStyle style() { return builtin != null ? BrushStyle.named(builtin.kind, builtin.style) : wild.style; }
    /** The same brush: the same built-in, or a Wild brush with the same name and settings. */
    boolean sameAs(Brush other) {
        if (other == null) return false;
        return builtin != null ? builtin == other.builtin : other.wild != null && wild.sameAs(other.wild);
    }
    /** As stored: "@INK" for a built-in; a Wild brush's name and share code, tab-separated. */
    String write() { return builtin != null ? "@" + builtin.name() : clean(wild.name) + "\t" + BrushCode.encode(wild); }
    /** A stored brush, or null if it doesn't read. */
    static Brush read(String text) {
        if (text == null) return null;
        if (text.startsWith("@")) {
            try { return of(BuiltinBrush.valueOf(text.substring(1))); }
            catch (IllegalArgumentException e) { return null; }
        }
        int tab = text.indexOf('\t');
        if (tab < 0) return null;
        WildBrush b = BrushCode.decode(text.substring(tab + 1));
        if (b == null) return null;
        String name = clean(text.substring(0, tab));
        if (!name.isEmpty()) b.name = name;
        return of(b);
    }
    /** A name as kept: one line, single spaces, at most {@link #NAME_MAX} characters. */
    static String clean(String name) {
        String clean = name.replaceAll("\\s+", " ").trim();
        return clean.length() > NAME_MAX ? clean.substring(0, NAME_MAX).trim() : clean;
    }
}
```

```java
package io.github.mpdairy.monopaint;

import java.util.ArrayList;
import java.util.List;
import java.util.Locale;
import java.util.Random;
import java.util.Set;

/**
 * Brush Lab's variations, as the mockup's direction, apply, describe and makeVars: each pushes two or three
 * unlocked settings one way, within the style's range widened to take in a value dragged past it.
 * Pure, checked on the desktop.
 */
final class BrushVariations {
    static final int COUNT = 6;

    /** One setting pushed one way: a dial by {@link #delta}, kept within {@link #lo} to {@link #hi}; or a choice moved to option {@link #to}. */
    static final class Push {
        final BrushSetting setting;
        final double delta, lo, hi;
        final int to;
        private Push(BrushSetting setting, double delta, double lo, double hi, int to) { this.setting = setting; this.delta = delta; this.lo = lo; this.hi = hi; this.to = to; }
    }
    /** A variation and its caption ("more splatter / less taper in"). */
    static final class Variation {
        final Brush brush;
        final List<String> caption;
        Variation(Brush brush, List<String> caption) { this.brush = brush; this.caption = caption; }
    }

    private BrushVariations() { }

    /** Six variations of {@code brush}, leaving {@code locks} alone: a built-in's are Wild brushes in its approximation's style. */
    static List<Variation> make(Brush brush, Set<BrushSetting> locks, Random random) {
        WildBrush b = brush.settings();
        List<Variation> made = new ArrayList<>();
        for (int k = 0; k < COUNT; k++) {
            List<Push> pushes = direction(b, locks, random);
            WildBrush v = apply(b, pushes, random.nextInt() & 0xffffffffL);
            v.name = brush.builtin != null ? BrushNames.pick(BrushNames.adjectives(), random) + "-" + brush.builtin.label.toLowerCase(Locale.ROOT)
                    : BrushNames.kin(b.name, random);
            made.add(new Variation(Brush.of(v), describe(pushes)));
        }
        return made;
    }

    /** Which settings a variation pushes, and which way: only what the style lets vary, and nothing locked. */
    static List<Push> direction(WildBrush b, Set<BrushSetting> locks, Random random) {
        BrushStyle style = b.style;
        List<BrushSetting> pool = new ArrayList<>();
        for (BrushSetting s : BrushSetting.of(b.kind)) if (!locks.contains(s) && (s.choice() || s.active(b)) && varies(style, b, s)) pool.add(s);
        List<Push> pushes = new ArrayList<>();
        int count = 2 + (random.nextDouble() < .4 ? 1 : 0);
        while (pushes.size() < count && !pool.isEmpty()) {
            BrushSetting s = pool.remove(random.nextInt(pool.size()));
            if (s.choice()) {
                if (random.nextDouble() < .5) continue;
                int current = (int)s.get(b);
                List<Integer> others = new ArrayList<>();
                int[] options = style.options(s);
                if (options == null) { for (int o = 0; o < s.choices.length; o++) if (o != current) others.add(o); }
                else for (int o : options) if (o != current) others.add(o);
                if (others.isEmpty()) continue;
                pushes.add(new Push(s, 0, 0, 0, others.get(random.nextInt(others.size()))));
                continue;
            }
            // Within the style's band, widened to take in a value dragged past it.
            double[] band = style.band(b, s);
            double v = s.get(b), lo = Math.min(band == null ? s.min : band[0], v), hi = Math.max(band == null ? s.max : band[1], v), span = hi - lo;
            double rel = (v - lo) / (span == 0 ? 1 : span);
            int sign = random.nextDouble() < .5 ? -1 : 1;
            if (rel < .08) sign = 1; else if (rel > .92) sign = -1;
            pushes.add(new Push(s, sign * lerp(.35, .8, random.nextDouble()) * span, lo, hi, 0));
        }
        return pushes;
    }
    /** {@code b} with {@code pushes} applied and seed {@code seed}. A texture pushed on shows at least half strength. */
    static WildBrush apply(WildBrush b, List<Push> pushes, long seed) {
        WildBrush c = b.copy(seed);
        for (Push p : pushes) {
            if (p.setting.choice()) {
                p.setting.set(c, p.to);
                if (p.setting == BrushSetting.TEXTURE && p.to != BrushTexture.PLAIN.ordinal()) {
                    BrushSetting strength = BrushSetting.strength(c.kind);
                    strength.set(c, Math.max(strength.get(c), .5));
                }
                continue;
            }
            double v = Math.max(p.lo, Math.min(p.hi, p.setting.get(b) + p.delta));
            if (p.setting.min == 0 && v < .04) v = 0;
            p.setting.set(c, v);
        }
        return c.normalize();
    }
    /** A variation's caption: "more splatter", "less taper in", "chisel nib", "felt", "wet paint". */
    static List<String> describe(List<Push> pushes) {
        List<String> items = new ArrayList<>();
        for (Push p : pushes) {
            if (!p.setting.choice()) { items.add((p.delta > 0 ? "more " : "less ") + p.setting.shortLabel); continue; }
            String option = p.setting.choices[p.to];
            items.add(p.setting == BrushSetting.NIB ? option + " nib" : p.setting == BrushSetting.TEXTURE ? option : option + " paint");
        }
        return BrushCaptions.twoLines(items);
    }

    private static boolean varies(BrushStyle style, WildBrush b, BrushSetting s) {
        if (style.wild()) return true;
        if (s.choice()) { int[] options = style.options(s); return options != null && options.length > 1; }
        if (s == BrushSetting.ASPECT) return true;
        double[] band = style.band(b, s);
        return band[1] > band[0];
    }
    private static double lerp(double a, double b, double t) { return a + (b - a) * t; }
}
```

```java
 * scribble-loop's centre line), light at the ends, firm through the middle and slower where firm, as the Brush

     * The mockup's loopPoints: Catmull-Rom through {@link #LOOP} about every two pixels, scaled to fit
     * {@code width × height} inside {@code pad}, placed at {@code x0, y0}. Each point is {x, y, pressure travel
     * 0–1, time in ms}; a point under .6 px from the last is left out, as the mockup's addPoint does.

    static float[][] loop(float width, float height, float pad, float x0, float y0) {
        double scale = Math.min((width - 2 * pad) / LOOP_WIDTH, (height - 2 * pad) / LOOP_HEIGHT);
        double ox = x0 + (width - LOOP_WIDTH * scale) / 2 - LOOP_LEFT * scale, oy = y0 + (height - LOOP_HEIGHT * scale) / 2 - LOOP_TOP * scale;
        int n = LOOP.length;

            double[] p0 = p[Math.max(0, i - 1)], p1 = p[i], p2 = p[i + 1], p3 = p[Math.min(n - 1, i + 2)];
            int steps = Math.max(2, (int)Math.ceil(Math.hypot(p2[0] - p1[0], p2[1] - p1[1]) / 2));
            for (int s = 0; s < steps; s++) {
                double t = (double)s / steps, t2 = t * t, t3 = t2 * t;
                double[] q = new double[2];
                for (int k = 0; k < 2; k++)
                    q[k] = .5 * (2 * p1[k] + (-p0[k] + p2[k]) * t + (2 * p0[k] - 5 * p1[k] + 4 * p2[k] - p3[k]) * t2 + (-p0[k] + 3 * p1[k] - 3 * p2[k] + p3[k]) * t3);
                dense.add(q);
            }
        }

        page.render(pixels, 0, 0, width, height);
        return pixels;
    }
```

```java
package io.github.mpdairy.monopaint;

import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

/**
 * Every brush that can go in a slot: the four built-ins, which can't be deleted, so they can always be put back,
 * and saved brushes, newest first, without limit. Each entry is stamped when saved or put in a slot, so the four
 * most recently used fill a slot's panel. Kept between launches in a tiny key/value store; read each time, so two
 * screens sharing the store always agree. Pure, checked on the desktop.
 */
final class BrushLibrary {
    /** Where the library is kept: SharedPreferences on the device, a map in the checks. A null value removes the key. */
    interface Store { String get(String key); void put(String key, String value); }
    enum Saved { ADDED, ALREADY }
    /** A library brush: its place ({@link #id}s rise with each save), when it was last saved or used, and the brush. */
    static final class Entry {
        final long id, used;
        final Brush brush;
        Entry(long id, long used, Brush brush) { this.id = id; this.used = used; this.brush = brush; }
        /** Built-ins stay, so they can always be put back. */
        boolean deletable() { return brush.builtin == null; }
    }

    /** The entries, one a line: id, stamp and the stored brush, tab-separated. The last id or stamp given out. */
    private static final String LIBRARY = "brush_library", STAMP = "brush_stamp";
    private final Store store;

    BrushLibrary(Store store) { this.store = store; }

    /** The built-ins in their order, then saved brushes, newest first. */
    List<Entry> entries() {
        List<Entry> all = read(), entries = new ArrayList<>();
        for (BuiltinBrush builtin : BuiltinBrush.values()) for (Entry e : all) if (e.brush.builtin == builtin) entries.add(e);
        entries.addAll(saved(all));
        return entries;
    }
    /** Saved brushes, newest first. */
    List<Entry> saved() { return saved(read()); }
    /** The {@code count} entries saved or used last, latest first. */
    List<Entry> recent(int count) {
        List<Entry> all = read();
        Collections.sort(all, (a, b) -> a.used != b.used ? Long.compare(b.used, a.used) : Long.compare(b.id, a.id));
        return new ArrayList<>(all.subList(0, Math.min(count, all.size())));
    }
    /** The entry holding {@code brush}, or null. */
    Entry find(Brush brush) { return find(read(), brush); }
    boolean contains(Brush brush) { return find(brush) != null; }
    /** Adds {@code brush}, newest; one already here (a built-in, or the same name and settings) is stamped as used instead. */
    Saved save(Brush brush) {
        List<Entry> all = read();
        long stamp = next();
        Entry found = find(all, brush);
        if (found != null) { all.set(all.indexOf(found), new Entry(found.id, stamp, found.brush)); write(all); return Saved.ALREADY; }
        all.add(new Entry(stamp, stamp, brush));
        write(all);
        return Saved.ADDED;
    }
    /** {@code brush} was put in a slot: if it is in the library, it is now the most recently used. */
    void used(Brush brush) {
        List<Entry> all = read();
        Entry found = find(all, brush);
        if (found == null) return;
        all.set(all.indexOf(found), new Entry(found.id, next(), found.brush));
        write(all);
    }
    /** Deletes saved entry {@code id}; built-ins and unknown ids stay. */
    boolean delete(long id) {
        List<Entry> all = read();
        for (Entry e : all) if (e.id == id && e.deletable()) { all.remove(e); write(all); return true; }
        return false;
    }

    private static List<Entry> saved(List<Entry> all) {
        List<Entry> saved = new ArrayList<>();
        for (Entry e : all) if (e.deletable()) saved.add(e);
        Collections.sort(saved, (a, b) -> Long.compare(b.id, a.id));
        return saved;
    }
    private static Entry find(List<Entry> all, Brush brush) {
        for (Entry e : all) if (e.brush.sameAs(brush)) return e;
        return null;
    }
    /** The stored entries; lines that don't read are dropped, and a built-in that went missing comes back. */
    private List<Entry> read() {
        List<Entry> all = new ArrayList<>();
        String text = store.get(LIBRARY);
        if (text != null) for (String line : text.split("\n")) {
            String[] parts = line.split("\t", 3);
            if (parts.length < 3) continue;
            Brush brush = Brush.read(parts[2]);
            if (brush == null) continue;
            try { all.add(new Entry(Long.parseLong(parts[0]), Long.parseLong(parts[1]), brush)); } catch (NumberFormatException ignored) { }
        }
        for (BuiltinBrush builtin : BuiltinBrush.values()) {
            boolean present = false;
            for (Entry e : all) present |= e.brush.builtin == builtin;
            if (!present) all.add(new Entry(builtin.ordinal() + 1, 0, Brush.of(builtin)));
        }
        return all;
    }
    private void write(List<Entry> all) {
        StringBuilder text = new StringBuilder();
        for (Entry e : all) {
            if (text.length() > 0) text.append('\n');
            text.append(e.id).append('\t').append(e.used).append('\t').append(e.brush.write());
        }
        store.put(LIBRARY, text.toString());
    }
    /** The next id or stamp, after the built-ins' 1 to 4. */
    private long next() {
        long last = BuiltinBrush.values().length;
        try { String stored = store.get(STAMP); if (stored != null) last = Math.max(last, Long.parseLong(stored)); } catch (NumberFormatException ignored) { }
        store.put(STAMP, Long.toString(last + 1));
        return last + 1;
    }
}
```

```java
package io.github.mpdairy.monopaint;

import java.util.ArrayDeque;
import java.util.List;
import java.util.Random;

/**
 * The bar's six tool slots. Any slot holds any library brush (see {@link Brush}): a built-in, a Wild pen or a Wild
 * paint, whose kind, not the slot, decides where it draws. Each slot's dice rolls a new brush in its brush's style;
 * a pick puts a library brush in it. Undo takes back rolls and picks made since the page last changed, latest
 * first, before it undoes the page. Kept between launches; the first launch moves the old tools' prefs over.
 * Pure, checked on the desktop.
 */
final class ToolSlots {
    static final int COUNT = 6;
    /** How many recently used library brushes a slot's panel offers. */
    static final int RECENT = 4;
    /** How many rolls and picks Undo can take back. */
    static final int UNDOS = 32;
    /** The Wild brushes a first launch starts on: the roll tester's opening seeds, wobbly-goose and wobbly-owl. */
    static final long FIRST_INK = 505, FIRST_PAINT = 625;
    /** Each slot's (or the eraser's) size and shade are kept under these plus {@link #key}; the selection under {@link #SELECTED}. */
    static final String SIZE = "inkwash_size_", SHADE = "inkwash_shade_", SELECTED = "inkwash_tool";
    /** The bar's tools before slots, in slot order: the names their sizes, shades and selection were kept under. */
    static final String[] OLD_TOOLS = {"INK", "FUDE", "WILD_INK", "WASH", "WATERCOLOR", "WILD_PAINT"};
    /** The six slots' stored brushes, one a line; and the old Wild tools' seeds, read once by the migration. */
    private static final String SLOTS = "tool_slots", OLD_CURRENT = "wild_current_", OLD_SAVED = "wild_saved_";

    final BrushLibrary library;
    private final BrushLibrary.Store store;
    private final Random dice;
    /** The rolls and picks since the page last changed, latest last: each slot and its brush before. Not kept between launches. */
    private final ArrayDeque<Change> changes = new ArrayDeque<>();
    private static final class Change {
        final int slot;
        final String before;
        Change(int slot, String before) { this.slot = slot; this.before = before; }
    }

    ToolSlots(BrushLibrary.Store store, Random dice) {
        this.store = store; this.dice = dice; library = new BrushLibrary(store);
        if (store.get(SLOTS) == null) start();
    }

    /** The key a slot's size, shade and selection are kept under. */
    static String key(int slot) { return "slot" + slot; }
    /** What slot {@code slot} holds on a first launch: the bar as it was. */
    static Brush first(int slot) {
        switch (slot) {
            case 0: return Brush.of(BuiltinBrush.INK);
            case 1: return Brush.of(BuiltinBrush.FUDE);
            case 2: return Brush.of(WildBrush.roll(WildBrush.Kind.INK, FIRST_INK));
            case 3: return Brush.of(BuiltinBrush.WASH);
            case 4: return Brush.of(BuiltinBrush.WATERCOLOR);
            default: return Brush.of(WildBrush.roll(WildBrush.Kind.PAINT, FIRST_PAINT));
        }
    }
    /** Slot {@code slot}'s brush; one that doesn't read is what the slot started with. */
    Brush brush(int slot) {
        Brush brush = Brush.read(stored()[slot]);
        return brush != null ? brush : first(slot);
    }
    /** The dice: a new brush in the slot brush's style, for this slot only. */
    Brush roll(int slot) {
        Brush rolled = Brush.of(brush(slot).style().roll(dice));
        change(slot, rolled);
        return rolled;
    }
    /** Puts {@code brush} in slot {@code slot}; a library brush becomes the most recently used. */
    void use(int slot, Brush brush) {
        change(slot, brush);
        library.used(brush);
    }
    BrushLibrary.Saved save(int slot) { return library.save(brush(slot)); }
    boolean isSaved(int slot) { return library.contains(brush(slot)); }
    /** The library brushes a slot's panel offers: the {@link #RECENT} saved or used last. */
    List<BrushLibrary.Entry> recent() { return library.recent(RECENT); }
    /** Whether Undo would take back a roll or a pick rather than undo the page. */
    boolean canUndo() { return !changes.isEmpty(); }
    /** Takes back the latest roll or pick: its slot goes back to the brush it had. Returns that slot, or -1 if there is none. */
    int undo() {
        Change last = changes.pollLast();
        if (last == null) return -1;
        set(last.slot, last.before);
        return last.slot;
    }
    /** The page changed, or is about to (a stroke starts, Undo or Redo changes it): Undo is the page's again. */
    void pageChanged() { changes.clear(); }

    private void change(int slot, Brush brush) {
        Brush before = brush(slot);
        if (before.sameAs(brush)) return;
        changes.addLast(new Change(slot, before.write()));
        if (changes.size() > UNDOS) changes.removeFirst();
        set(slot, brush.write());
    }
    private String[] stored() {
        String[] lines = new String[COUNT];
        String text = store.get(SLOTS);
        if (text != null) {
            String[] parts = text.split("\n", -1);
            System.arraycopy(parts, 0, lines, 0, Math.min(COUNT, parts.length));
        }
        return lines;
    }
    /** Stores slot {@code slot} as {@code text}, and every other slot as it reads. */
    private void set(int slot, String text) {
        String[] lines = new String[COUNT];
        for (int i = 0; i < COUNT; i++) lines[i] = i == slot ? text : brush(i).write();
        store.put(SLOTS, String.join("\n", lines));
    }
    /**
     * A first launch with slots: the bar's tools become the six slots, keeping each tool's size and shade and the
     * selection. Each old Wild tool's current seed becomes its slot's brush and its saved seeds library brushes,
     * with the settings the seed rolls, style Wild, texture plain and their old names.
     */
    private void start() {
        String[] lines = new String[COUNT];
        for (int i = 0; i < COUNT; i++) lines[i] = first(i).write();
        for (WildBrush.Kind kind : WildBrush.Kind.values()) {
            String saved = store.get(OLD_SAVED + kind.name());
            if (saved != null) for (String part : saved.split(",")) {
                Long seed = seed(part);
                if (seed != null) library.save(Brush.of(WildBrush.roll(kind, seed)));
            }
            Long current = seed(store.get(OLD_CURRENT + kind.name()));
            if (current != null) lines[kind == WildBrush.Kind.INK ? 2 : 5] = Brush.of(WildBrush.roll(kind, current)).write();
            store.put(OLD_SAVED + kind.name(), null);
            store.put(OLD_CURRENT + kind.name(), null);
        }
        for (int i = 0; i < COUNT; i++) { move(SIZE + OLD_TOOLS[i], SIZE + key(i)); move(SHADE + OLD_TOOLS[i], SHADE + key(i)); }
        String selected = store.get(SELECTED);
        for (int i = 0; i < COUNT; i++) if (OLD_TOOLS[i].equals(selected)) store.put(SELECTED, key(i));
        store.put(SLOTS, String.join("\n", lines));
    }
    private void move(String from, String to) {
        String value = store.get(from);
        if (value == null) return;
        store.put(to, value);
        store.put(from, null);
    }
    private static Long seed(String text) {
        if (text == null) return null;
        try { return Long.parseLong(text.trim()) & 0xffffffffL; } catch (NumberFormatException e) { return null; }
    }
}
```

```java
package io.github.mpdairy.monopaint;

import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.EnumSet;
import java.util.List;
import java.util.Locale;
import java.util.Random;

/**
 * Brush Lab's state, as the mockup's: the brush being worked on (opened from a slot, edited for that slot),
 * the settings locked, its six variations, the lab's own Undo, the status line and the library's cards.
 * Changing a built-in makes the lab's own Wild copy, "my-ink". The library is written at once (Save,
 * delete); the slot only takes the brush when the drawing screen does, on Back. Pure, checked on the desktop.
 */
final class BrushLab {
    /** How many changes Undo can take back. */
    static final int HISTORY = 40;

    /** A library card: a brush, the slot it is in (-1 for none), and the saved entry it stands for (null for none). */
    static final class Card {
        final Brush brush;
        final int slot;
        final BrushLibrary.Entry entry;
        Card(Brush brush, int slot, BrushLibrary.Entry entry) { this.brush = brush; this.slot = slot; this.entry = entry; }
        List<String> caption() { return BrushCaptions.describe(brush); }
        /** Saved brushes can be deleted; built-ins and brushes only in a slot can't. */
        boolean deletable() { return entry != null && entry.deletable(); }
    }

    final ToolSlots slots;
    /** The slot the lab was opened from, which Back returns the brush to. */
    final int slot;
    final EnumSet<BrushSetting> locks = EnumSet.noneOf(BrushSetting.class);
    List<BrushVariations.Variation> variations;
    /** Short, factual feedback for the status line. */
    String status;
    private final Random random;
    /** Brushes before each change, latest last; a Wild brush is copied before it changes. */
    private final ArrayDeque<Brush> history = new ArrayDeque<>();
    private Brush brush;
    /** {@link #brush}'s settings: the Wild brush itself, or a built-in's approximation, which never changes. */
    private WildBrush settings;

    BrushLab(ToolSlots slots, int slot, Random random) {
        this.slots = slots; this.slot = slot; this.random = random;
        show(copyOf(slots.brush(slot)));
        variations = BrushVariations.make(brush, locks, random);
        status = opened();
    }

    Brush brush() { return brush; }
    WildBrush settings() { return settings; }
    boolean canUndo() { return !history.isEmpty(); }
    /** The brush's share code (a built-in's is its approximation's). */
    String code() { return BrushCode.encode(settings); }
    /** What Back returns: the lab's brush, for the slot it was opened from. */
    Brush result() { return brush; }
    /** Whether {@code card} is the brush in the lab. */
    boolean now(Card card) { return card.brush.sameAs(brush); }

    /** Opens a library brush in the lab. */
    void open(Brush picked) {
        if (picked.sameAs(brush)) return;
        remember();
        show(copyOf(picked));
        fresh();
        status = opened();
    }
    void pickVariation(int index) {
        BrushVariations.Variation v = variations.get(index);
        remember();
        show(copyOf(v.brush));
        fresh();
        status = v.brush.name() + ": " + String.join(", ", v.caption);
    }
    /** Six new variations; not a change Undo takes back. */
    void newVariations() {
        fresh();
        status = "Six new variations.";
    }
    /** A new brush in the brush's style, keeping what's locked. */
    void randomize() {
        WildBrush old = settings;
        remember();
        WildBrush b = keepLocked(old, brush.style().roll(random));
        show(Brush.of(b));
        fresh();
        status = "Randomized: " + b.name + ", " + (b.style.wild() ? "wild" : "a " + b.style.name + " " + noun()) + keeping() + ".";
    }
    /** A new brush in {@code style}, keeping what's locked. */
    void pickStyle(BrushStyle style) {
        if (style == brush.style()) return;
        WildBrush old = settings;
        remember();
        WildBrush b = keepLocked(old, style.roll(random));
        show(Brush.of(b));
        fresh();
        status = "A new " + style.name + " " + noun() + ": " + b.name + ". Roll for another.";
    }
    /** A slider is pressed: remembers the brush for Undo, and a built-in becomes the lab's own copy. */
    void startSlide() { edit(); }
    /** A slider moves: the setting follows, or for Speed its amount, keeping its direction. Not yet a change for the variations. */
    void slide(BrushSetting setting, double value) {
        if (setting != BrushSetting.SPEED) { setting.set(settings, value); return; }
        int direction = settings.speedDirection();
        settings.thickerWhenFast = direction > 0;
        settings.speed = direction * value;
    }
    /** A slider is let go. */
    void endSlide(BrushSetting setting) {
        settings.normalize();
        fresh();
        status = setting.label + " set to " + setting.shown(settings) + "." + copied();
    }
    /** A choice's chip. A texture needs some strength to show: under .35, its strength becomes .5. */
    void choose(BrushSetting setting, int option) {
        if ((int)setting.get(settings) == option) return;
        WildBrush b = edit();
        setting.set(b, option);
        if (setting == BrushSetting.TEXTURE && option != BrushTexture.PLAIN.ordinal()) {
            BrushSetting strength = BrushSetting.strength(b.kind);
            if (strength.get(b) < .35) strength.set(b, .5);
        }
        b.normalize();
        fresh();
        status = setting.label + ": " + setting.choices[option] + "." + copied();
    }
    /** A setting's own dice, within the style. */
    void roll(BrushSetting setting) {
        WildBrush b = edit();
        b.style.rollSetting(b, setting, random);
        fresh();
        status = setting.label + " rolled to " + setting.shown(b) + "." + copied();
    }
    /** Speed's switch: thinner or thicker when fast, at amount .4 if it was off. */
    void flipSpeed() {
        WildBrush b = edit();
        int direction = -b.speedDirection();
        b.thickerWhenFast = direction > 0;
        b.speed = direction * (b.speed != 0 ? Math.abs(b.speed) : .4);
        fresh();
        status = "Speed: " + (direction < 0 ? "thinner" : "thicker") + " when fast." + copied();
    }
    void toggleLock(BrushSetting setting) { if (!locks.remove(setting)) locks.add(setting); }
    /** Renames the brush; false, changing nothing, for an empty or unchanged name. */
    boolean rename(String name) {
        String clean = Brush.clean(name);
        if (clean.isEmpty() || clean.equals(brush.name())) return false;
        WildBrush b = edit();
        b.name = clean;
        status = "Renamed to " + clean + "." + copied();
        return true;
    }
    /** Takes back the latest change: switching, settings, randomize, rename. */
    void undo() {
        if (history.isEmpty()) return;
        show(history.pollLast());
        fresh();
        status = "Back to " + brush.name() + ".";
    }
    /** Adds the brush to the library; a built-in, or a brush saved before, is there already. */
    void save() {
        BrushLibrary.Saved saved = slots.library.save(brush);
        status = saved == BrushLibrary.Saved.ADDED ? "Saved " + brush.name() + "." : brush.name() + " is in the library already.";
    }
    /** Opens the brush a pasted share code describes; false, changing nothing, if it doesn't read. */
    boolean load(String code) {
        WildBrush b = BrushCode.decode(code);
        if (b == null) { status = "That code didn't read. A share code looks like dapper-fig.I6…, copied whole."; return false; }
        remember();
        show(Brush.of(b));
        fresh();
        status = "Loaded " + b.name + " from its code. Save it to keep it in the library.";
        return true;
    }
    /**
     * The library's cards: the six slots' brushes in bar order (a slot brush that is also saved stands for that
     * entry), then the built-ins in no slot, then the other saved brushes, newest first.
     */
    List<Card> library() {
        List<Card> cards = new ArrayList<>();
        List<BrushLibrary.Entry> saved = slots.library.saved(), shown = new ArrayList<>();
        EnumSet<BuiltinBrush> inSlots = EnumSet.noneOf(BuiltinBrush.class);
        for (int i = 0; i < ToolSlots.COUNT; i++) {
            Brush b = slots.brush(i);
            BrushLibrary.Entry entry = null;
            for (BrushLibrary.Entry e : saved) if (!shown.contains(e) && e.brush.sameAs(b)) { entry = e; break; }
            if (entry != null) shown.add(entry);
            if (b.builtin != null) inSlots.add(b.builtin);
            cards.add(new Card(b, i, entry));
        }
        for (BuiltinBrush b : BuiltinBrush.values()) if (!inSlots.contains(b)) cards.add(new Card(Brush.of(b), -1, null));
        for (BrushLibrary.Entry e : saved) if (!shown.contains(e)) cards.add(new Card(e.brush, -1, e));
        return cards;
    }
    /** Deletes a saved card's brush from the library; false for one that can't be deleted. */
    boolean delete(Card card) {
        if (!card.deletable()) return false;
        slots.library.delete(card.entry.id);
        status = "Deleted " + card.brush.name() + ".";
        return true;
    }

    /** Before a change: remembers the brush for Undo, and a built-in becomes the lab's own Wild copy. Returns the brush to change. */
    private WildBrush edit() {
        remember();
        if (brush.builtin != null) {
            WildBrush copy = settings.copy(random.nextInt() & 0xffffffffL);
            copy.name = "my-" + brush.builtin.label.toLowerCase(Locale.ROOT);
            show(Brush.of(copy));
        }
        return settings;
    }
    /** " Your own copy now." when this change made a built-in the lab's own copy. */
    private String copied() { return !history.isEmpty() && history.peekLast().builtin != null ? " Your own copy now." : ""; }
    private void remember() {
        history.addLast(copyOf(brush));
        if (history.size() > HISTORY) history.removeFirst();
    }
    private void show(Brush b) { brush = b; settings = b.settings(); }
    /** The brush changed: six new variations of it. */
    private void fresh() { variations = BrushVariations.make(brush, locks, random); }
    private WildBrush keepLocked(WildBrush from, WildBrush to) {
        for (BrushSetting s : locks) if (BrushSetting.of(to.kind).contains(s)) s.set(to, s.get(from));
        if (locks.contains(BrushSetting.SPEED)) to.thickerWhenFast = from.thickerWhenFast;
        return to.normalize();
    }
    private String keeping() {
        List<String> kept = new ArrayList<>();
        for (BrushSetting s : BrushSetting.of(settings.kind)) if (locks.contains(s)) kept.add(s.label.toLowerCase(Locale.ROOT));
        return kept.isEmpty() ? "" : ", keeping " + String.join(", ", kept);
    }
    private String noun() { return settings.kind == WildBrush.Kind.INK ? "pen" : "paint"; }
    private String opened() { return brush.name() + " · " + brush.style().name + (brush.builtin != null ? " · built in: changes make your own copy" : ""); }
    private static Brush copyOf(Brush b) { return b.wild != null ? Brush.of(b.wild.copy()) : b; }
}
```

```java
package io.github.mpdairy.monopaint;

import android.view.MotionEvent;

/** One pen sample read from a MotionEvent as the strokes take it: position, pressure, Supernote's signed tilt degrees and the input's own clock. */
final class PenSample {
    float x, y, pressure, tiltX, tiltY;
    long time;

    /**
     * Reads pointer {@code index}'s sample {@code history} (-1 for the current one) of {@code event}. Tilt comes from
     * {@code physical}, the untransformed event, when given (Android would rotate its axes with the app); the
     * position stays the event's. {@code landscapeTilt}: see {@link Device#landscapeTilt}.
     */
    void read(MotionEvent event, MotionEvent physical, int index, int history, boolean landscapeTilt) {
        if (physical == null) physical = event;
        int source = physical.findPointerIndex(event.getPointerId(index));
        if (source < 0 || history >= physical.getHistorySize()) { physical = event; source = index; }
        boolean current = history < 0;
        x = current ? event.getX(index) : event.getHistoricalX(index, history);
        y = current ? event.getY(index) : event.getHistoricalY(index, history);
        pressure = current ? event.getPressure(index) : event.getHistoricalPressure(index, history);
        // The input's own clock, so strokes follow the pen's speed (see PenSpeed).
        time = current ? event.getEventTime() : event.getHistoricalEventTime(history);
        // Supernote encodes signed X degrees in ORIENTATION, Y in TILT; treating ORIENTATION as Android azimuth corrupts tilt.
        tiltX = current ? physical.getOrientation(source) : physical.getHistoricalOrientation(source, history);
        tiltY = current ? physical.getAxisValue(MotionEvent.AXIS_TILT, source) : physical.getHistoricalAxisValue(MotionEvent.AXIS_TILT, source, history);
        if (landscapeTilt) { float panelX = tiltX; tiltX = -tiltY; tiltY = panelX; }
    }
}
```

```java
        stroke.sample(pen.x, pen.y, pen.pressure, pen.tiltX, pen.tiltY, pen.time);
    }
    /** Ends a stroke in progress, laying what it lays on lift. */
    void finishStroke() {
        if (stroke == null) return;
        stroke.finish();
        stroke = null; pointer = -1;
        getParent().requestDisallowInterceptTouchEvent(false);
        renderDirty();
        removeCallbacks(refresh); postDelayed(refresh, DrawingPad.PEN_AWAY_MS);
    }

    // Rendering and presenting

    private void renderAll() { if (display != null) render(new Rect(0, 0, display.getWidth(), display.getHeight())); }
    private void renderDirty() {
        int[] b = page.dirty();
        if (b == null) return;
        page.clearDirty();
        render(new Rect(b[0] - 2, b[1] - 2, b[2] + 2, b[3] + 2));
    }
    /** Renders {@code area} of the page in its dots, then the corner over it, and presents it. */
    private void render(Rect area) {
        if (display == null || !area.intersect(0, 0, display.getWidth(), display.getHeight())) return;
        ViewportBitmap.compose(page, display, true, area);
        if (!cornerArea.isEmpty()) {
            Rect framed = new Rect(cornerArea); framed.inset(-FRAME, -FRAME);
            if (Rect.intersects(area, framed)) {
                onDisplay.drawRect(framed.left, framed.top, framed.right, cornerArea.top, ink);
                onDisplay.drawRect(framed.left, cornerArea.bottom, framed.right, framed.bottom, ink);
                onDisplay.drawRect(framed.left, cornerArea.top, cornerArea.left, cornerArea.bottom, ink);
                onDisplay.drawRect(cornerArea.right, cornerArea.top, framed.right, cornerArea.bottom, ink);
                Rect inside = new Rect(area);
                if (inside.intersect(cornerArea)) {
                    if (corner == null) onDisplay.drawRect(inside, paper);
                    else display.setPixels(corner, (inside.top - cornerArea.top) * CORNER_WIDTH + inside.left - cornerArea.left, CORNER_WIDTH,
                            inside.left, inside.top, inside.width(), inside.height());
                }
            }
        }
        pending.union(area);
        flush();
    }
    private void flush() {
        removeCallbacks(retry);
        if (pending.isEmpty()) return;
        unrefreshed = true;
        if (direct == null) { invalidate(); pending.setEmpty(); return; }
        if (direct.present(display, pending) < 0) {
            // A busy display: try again shortly.
            if (++retries < 120) { postDelayed(retry, 8); return; }
        }
        retries = 0;
        pending.setEmpty();
    }
    /** Starts direct presentation and blocks the firmware's own pen ink, once the pad has its window and size. */
    void connect() {
        if (direct != null || display == null || !hasWindowFocus() || isLayoutRequested() || DirectEink.androidDrawing()) return;
        try {
            if (!input.prepareDocumentCanvas()) throw new IllegalStateException(input.status);
            direct = DirectEink.forView(this, display, new Matrix(), 0, 7);
            refreshSoon();
        } catch (RuntimeException | LinkageError error) {
            Log.w(ProbeActivity.TAG, "Brush Lab's test area uses Android drawing", error);
        }
    }
    /** Ends a stroke and gives the panel and the pen back, e.g. while a dialog or another screen is up. */
    void disconnect() {
        finishStroke();
        removeCallbacks(retry);
        if (direct != null) { direct.close(); direct = null; }
        input.disable();
    }
    void close() {
        disconnect();
        removeCallbacks(refresh);
        input.close();
        if (display != null) { display.recycle(); display = null; }
    }
    private void refreshSoon() { removeCallbacks(refresh); postDelayed(refresh, DrawingPad.CLOSED_MS); }
    /** One full, clean refresh of the pad, if it changed since the last; never under the pen. */
    private void refresh() {
        if (!unrefreshed || stroke != null || display == null) return;
        if (direct == null) { invalidate(); unrefreshed = false; return; }
        if (direct.refresh(display, new Rect(0, 0, display.getWidth(), display.getHeight())) < 0) { postDelayed(refresh, 8); return; }
        unrefreshed = false;
    }
}
```

```java
package io.github.mpdairy.monopaint;

import android.content.Context;
```

```java
/**
 * Brush Lab's library, under a heavy rule: every tool as a card (the loop in the brush, a two-line caption, the
 * name small), in {@link BrushLab#library}'s order. Paged, not scrolled (e-ink): as many cards as fit in two rows,
 * with previous and next. Long-press a saved brush to delete it, confirmed in the page's head.
 */
final class LabLibrary {
    static final int ROWS = 2;
    /** A card's narrowest width, dp: as the mockup's 128 px shelf cards. */
    static final int CARD_DP = 128;
    private final Context context;
    private final BrushLab lab;
    private final LinearLayout box;
    private final Runnable changed;
    private int page, width;
    /** The card waiting for its delete to be confirmed, or null. */
    private BrushLab.Card confirming;

    LabLibrary(Context context, BrushLab lab, LinearLayout box, Runnable changed) {
        this.context = context; this.lab = lab; this.box = box; this.changed = changed;
        // How many cards fit depends on the width: lay the pages out again when it is known or changes.
        box.addOnLayoutChangeListener((v, l, t, r, b, ol, ot, or, ob) -> { if (r - l != width) { width = r - l; box.post(this::render); } });
    }

    void render() {
        box.removeAllViews();
        List<BrushLab.Card> cards = lab.library();
        int room = width - box.getPaddingLeft() - box.getPaddingRight();
        int perRow = Math.max(1, room / dp(CARD_DP)), perPage = ROWS * perRow, pages = Math.max(1, (cards.size() + perPage - 1) / perPage);
        page = Math.max(0, Math.min(page, pages - 1));
        box.addView(head(pages), new LinearLayout.LayoutParams(-1, dp(52)));
        if (room <= 0) return;
        LinearLayout grid = LabUi.column(context);
        grid.setBackgroundColor(LabUi.INK);
        grid.setPadding(dp(2), dp(2), 0, 0);
        for (int r = 0; r < ROWS; r++) {
            int first = page * perPage + r * perRow;
            if (first >= cards.size()) break;
            LinearLayout row = LabUi.row(context);
            for (int c = 0; c < perRow; c++) {
                int index = first + c;
                LinearLayout.LayoutParams cell = new LinearLayout.LayoutParams(0, index < cards.size() ? -2 : -1, 1);
                cell.rightMargin = dp(2); cell.bottomMargin = dp(2);
                if (index < cards.size()) row.addView(card(cards.get(index)), cell);
                else { View empty = new View(context); empty.setBackgroundColor(LabUi.PAPER); row.addView(empty, cell); }
            }
            grid.addView(row, new LinearLayout.LayoutParams(-1, -2));
        }
        LinearLayout.LayoutParams margins = new LinearLayout.LayoutParams(-1, -2);
        margins.setMargins(dp(12), 0, dp(12), dp(12));
        box.addView(grid, margins);
    }

    /** "Tools", the page and previous and next; or, while a delete waits, the question and its answers. */
    private LinearLayout head(int pages) {
        LinearLayout head = LabUi.row(context);
        head.setPadding(dp(12), 0, dp(12), 0);

            LabUi.spring(head);

            delete.setOnClickListener(v -> { BrushLab.Card card = confirming; confirming = null; lab.delete(card); changed.run(); });
            head.addView(delete, new LinearLayout.LayoutParams(-2, dp(40)));
            LabButton keep = new LabButton(context, 0, "Keep", false, true);
            keep.setOnClickListener(v -> { confirming = null; render(); });
            LinearLayout.LayoutParams gap = new LinearLayout.LayoutParams(-2, dp(40)); gap.leftMargin = dp(8);
            head.addView(keep, gap);
            return head;
        }
        head.addView(LabUi.heading(context, "Tools"));
        LabUi.spring(head);
        TextView count = LabUi.text(context, (page + 1) + " / " + pages, 12, false);
        count.setPadding(0, 0, dp(8), 0);
        head.addView(count);
        LabButton previous = new LabButton(context, R.drawable.ic_ph_caret_left, null, false, true);

        previous.setEnabled(page > 0);
        previous.setOnClickListener(v -> { page--; render(); });
        head.addView(previous, new LinearLayout.LayoutParams(dp(44), dp(36)));
        LabButton next = new LabButton(context, R.drawable.ic_ph_caret_right, null, false, true);
        next.setContentDescription("Next page");
        next.setEnabled(page < pages - 1);
        next.setOnClickListener(v -> { page++; render(); });
        LinearLayout.LayoutParams gap = new LinearLayout.LayoutParams(dp(44), dp(36)); gap.leftMargin = dp(4);
        head.addView(next, gap);
        return head;
    }
    private View card(BrushLab.Card card) {

        if (card.deletable()) view.setOnLongClickListener(v -> { confirming = card; render(); return true; });
        return view;
    }
    private int dp(float value) { return Ui.dp(context, value); }
```
