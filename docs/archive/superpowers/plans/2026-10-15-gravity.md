# Gravity: page tilt moves wet paint (plan)

The owner approved the Gravity Lab prototype ("bring gravity into the app ... and the lab"): the reference is the web
prototype's `src/gravity.js` and its notes (`NOTES-gravity.md`; load = water + 1.2 · pigment, drips with necks, swells,
pinches, stalls and teardrop beads, pigment draining downhill inside an outline that stays, a pooled, beaded low
edge, no banding through the paper's tooth). Branch `inkwash-gravity` from `inkwash-v2-lab`; the owner integrates.
Checks after each task: `scripts/test_inkwash.sh`, `scripts/test_document.sh`, `./gradlew :app:assembleRelease`.

`PHILOSOPHY.md` #4 ("nothing moves on its own") already lets wet paint change for its few seconds; gravity moves only
paint that is still wet, only when the tablet is tilted, and never once it is dry.

## Rules that hold throughout

- **Old codes are untouched.** New dials go on the end of their choices' lists and into `ModularCode.ADDED`, so a brush
  that doesn't use them keeps its code byte for byte; rolls draw nothing new for them (Anything goes rolls them 0, as
  the prototype); variations leave a gravity dial at 0 alone. Proof: `LegacyConversionChecks` unchanged, the bench's
  210 page hashes unchanged, and a new check that brushes with gravity dials draw what they drew without them on a
  level page, and brushes without them draw the same at any tilt.
- **What never moves:** Instant (None), Cover, dry paint. A flow is built only once the page is actually tilted while
  the wash is wet, so a level page runs the old code path exactly.
- **The drying time** reaches a minute (the prototype's `wetMsOf`) only for a Slow brush with a gravity dial up; every
  other brush keeps 0.75–20 s, so no old code dries differently.

## Task 1: dials and words (pure)

- `PartDial`: Life `RUNS DRIPS G_POOL SINK BLEND`, Medium `DUST`, Hand `GS GD GW` ("Page tilt → size/dark/width");
  `PAGE_CELLS`, `GRID_CELLS` (the twelve cells). `wetMs(d, long)`.
- `PartChoice`: Quick += Runs, Pool, Sink; Slow += Runs, Drips, Pool, Sink, Blend; Charcoal += Dust; every hand +=
  the three page cells after Tilt range. `BrushPart` keeps: Life's Runs, Pool, Sink.
- `ModularCode.ADDED`, `ModularBrush.matchHand` over twelve cells, `ModularStyle` (Anything goes rolls them 0; Watercolor
  sometimes a little Runs/Pool; Charcoal and Pastels sometimes Dust; no style rolls Drips), `ModularVariations`.
- `ModularWords`: "Slow · 25 s · drips", "This brush" says what tilting does; the hand's page-tilt words.

## Task 2: the engine

- `PageTilt` (pure): the page's downhill vector after MonoPaint's dead zone (`CanvasGravity.FLAT`, about 4.6°).
- `ResolvedBrush`: `grav` (Slow: all five; Quick: Runs, Pool, Sink; null for None, Cover or all 0), `dust`, the hand's
  page-tilt factors on the pen, body and hake.
- `StrokePoints.ga`: travel direction · page tilt at each sample; the stampers scale size, darkness and nib width.
- `ModularStroke`: Quick's window settle runs, pools and sinks downhill (`gravWindow`); Charcoal's dust at lift.
- `DryingWater` holds a `GravityFlow` (new, the prototype's `Flow`): built at the first tilted tick, stepped every
  tick, the patch's settling routed into it; one gesture a tick; `finishNow` renders and stops it.
- `GravityFlow`: half-resolution cells (water, mobile pigment, grain, settled), runs, pairs, pool, edge flow, sink,
  settle, blooms, blend, drips (bead, spawn, width, wander, stall, merge, teardrop bead, trail store), render at every
  pixel through a float copy of the layer's tones, multiplicative. Heavy passes on `Cores` in row bands, gathered so
  the result doesn't depend on the split.
- `WatercolorSession`: the tilt source, `wantsTilt`, `tiltChanged`; ticks pass the tilt.

## Task 3: the sensor (Android)

- `CanvasGravity` (MonoPaint's, reused): also built from a plain `Context`; `read()` gives a `PageTilt`, honouring the
  display's rotation (the page never turns with Inkwash's app-only rotation, so its axes are the device's).
- `TiltFeed`: listens only while a tilt-reading stroke is down or a gravity wash is wet, and never while paused.
  Drawing screen (`InkWash`/`DrawingPad`) and Brush Lab (`BrushLabActivity`).

## Task 5: checks and measurements

- `GravityChecks` (desktop, from the prototype's gravity.cjs): runs move the centroid downhill; pigment conserved
  (ledger); the uphill part lightens, the low edge darkens and beads; no banding along a drip on plain paper; drips:
  count, width share and variation, stalls with a hard edge, straight at a steep tilt, darker bead, merge; sink, blend;
  None/Cover/dry never move; level = no motion; finish now; hand page tilt; dust; identical old codes; determinism.
- Bench: a gravity mode timing a big Drips wash's ticks (tilted, rocked) on the desktop and the Manta (bench packages
  only), against the 40 ms tick budget.
