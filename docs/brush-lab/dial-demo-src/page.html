Scribulor · Brush Lab

What each dial does

A Scribulor brush has six parts. Each part holds one choice, and each choice has its own dials. Every tile below draws the same stroke, the wave from Brush Lab's cards, while one thing changes: a choice's Basic slider, or one dial from low to high.

The tiles are drawn live by the web Brush Lab's engine, in the Manta's 16 greys. Names, ranges and steps are the lab's own.

  • Choices each with its Basic slider
  • Dials the Advanced dials, one at a time
  • After lift each setting played over time

Every tile uses the same stroke and the same seed, so the named dial is the only thing that changes. Everything else is at the lab's defaults: a round tip, dry ink, smooth paper and Quick drying, unless the tile says otherwise.

Drawn with the web Brush Lab's engine (docs/brush-lab/prototypes/modular-lab-src). Left out, as the web lab draws none of them: the runs, drips and pools of a tilted page, Control's page tilt, charcoal's dust, Grey Shift's own set of greys and the bristle's paint load.
